Sitemapper_XH - ein CMSimple_XH Plugin

Sitemapper_XH erzeugt automatisch eine XML-Sitemap Ihrer CMSimple_XC Installation. Ausführliche Information über Sitemaps erhalten Sie unter sitemaps.org.

Spezielle Version

Dies ist eine modifizierte Version der Version von github.com/cmb69 durch github.com/g7sim, die eine sitemap.xml dynamisch erzeugt. d.h. domäne.de/sitemap.xml.
